## 📌 Project Overview

This project is an interactive **Sales Analysis Dashboard** developed using Microsoft Power BI. The dashboard provides insights into sales performance, product analysis, regional sales distribution, and state-wise sales trends.

The main objective of this project is to transform sales data into meaningful visual insights that help understand business performance and support data-driven decision-making.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis
- Interactive Charts & Maps

## 📈 Key Performance Indicators (KPIs)

The dashboard includes the following KPI cards:

- **Total Sales:** 15M
- **Average Unit Price:** 17.14K
- **Total Quantity:** 925
- **Maximum Sales:** 540K

## 📊 Dashboard Visualizations

### 1. Sales by State
Analyzes total sales across different Indian states to identify state-wise sales performance.

### 2. Quantity by State
Displays the count of quantity records across different states using a horizontal bar chart.

### 3. Geographical Sales Analysis
Uses a map visualization to display the geographical distribution of states.

### 4. Sales by Product
Compares sales performance across different products, including:
- Laptop
- Mobile
- Monitor
- Headphones
- Keyboard

### 5. Maximum Unit Price by Product
Shows the maximum unit price for each product to compare product pricing.

### 6. Sales by Region
Analyzes sales distribution across five regions:
- North
- South
- East
- West
- Central

## 🎯 Key Objectives
